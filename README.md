# Brick Rigs Web

Неофіційний браузерний гараж для **Brick Rigs**: відкрий свої `.brv`-файли у 3D, роздивись машину зсередини й покатай її у маленькій пісочниці. Повну гру можна стрімити з власного ПК у вкладку — сайт підказує два робочі шляхи.

> Це фанатський інструмент, не пов'язаний з Fluppisoft. Сайт не хостить і не розповсюджує файли гри. Використовуй власну легальну копію Brick Rigs.

## Що вміє

- **Локальний перегляд `.brv`** — Three.js будує 3D-модель із цеглинок, кольорів, поворотів і розмірів. Файл не залишає браузер.
- **ZIP і тека гри** — можна перетягнути архів зі збереженнями або цілу теку Brick Rigs. Сайт знайде `.brv` і розпізнає теку гри.
- **Міні-пісочниця** — cannon-es: аркадна фізика, керування WASD/стрілками, сенсорні кнопки, скидання машини.
- **Повна гра у вкладці** — інструкції для GeForce NOW та MoonlightWeb (стрімінг з власного ПК), команда для картки застосунку, QR-код для телефона.
- **Українська за замовчуванням**, перемикач на англійську.
- **Темна/світла тема**, адаптивний інтерфейс, PWA та офлайн-оболонка.

## Запуск локально

```bash
cd brick-rigs-web
python3 -m http.server 4173
# відкрий http://localhost:4173
```

Модулі та `importmap` потребують HTTP-сервера; відкривання `index.html` як `file://` не працює.

Перевірки:

```bash
npm test
```

## Формат `.brv`

Читання формату зроблено за документацією та вихідним кодом [BrickEdit](https://github.com/MrPerruche/BrickEdit) (GPL-3.0). Парсер у `js/brv.js` читає геометрію, кольори, матеріали, розміри й колеса; він не претендує на повну підтримку всіх властивостей гри.

## Технології

- [Three.js](https://threejs.org/) — 3D-перегляд
- [cannon-es](https://github.com/pmndrs/cannon-es) — фізика пісочниці
- [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) — QR-код
- Вбудований `DecompressionStream` — читання ZIP без сервера

Усі бібліотеки лежать у `vendor/`, тож основна функціональність працює без CDN.
